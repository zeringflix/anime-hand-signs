# +1 Anime Eyes: map study from public YouTube storyboards (2026-11-02)

These are reference stills for layout only. Nothing from them is copied into the game.

- **Sources:** "Is +1 Anime Eyes ACTUALLY GOOD?!" (DKGBZlx7yzU) and "Starting Over as NOOB with BEST EYES in +1 Anime Eyes!" (GqlsNcj3KSo).
- **Lobby to Stage 1:** there is no walkway. The lobby's lavender studded floor runs straight up to a big pink gate wall. The gate reads "STAGE 1" with "RECOMMENDED CHAKRA 10" under it, and players walk through it.
- **Stage 1:** a lavender path between lime studded lawns, with grey stone lanterns lining both sides.
- **Later stages:** wide themed arenas, one after another:
  - green and brown
  - sakura pink
  - sand
  - orange and red
  - ice
  - teal
- **Stage parts:** each arena has a coloured studded floor, purple and yellow reward pads (+wins), and stepped studded cliffs as walls. A huge banner over each entrance reads "STAGE N / RECOMMENDED CHAKRA X", and boss stages are marked "BOSS: ...".
- **HUD:** the main counter above the level bar reads "N Chakra".
